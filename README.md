# Game Timer

Game Timer — десктоп‑приложение на Python (PyQt6) для дружелюбного контроля игрового времени с уведомлениями, авто‑стартом таймера и блокировкой.

## Основные возможности

- ⏱️ Ручной и авто‑старт таймера по обнаружению игры
- 🪟 При обнаружении игры таймер запускается автоматически; уведомление с кнопкой «Понятно» можно закрыть или свернуть — учёт продолжится
- 🔔 Уведомление «Время истекло» с проверкой — если игра не закрыта, запускается блокировка
- 🧭 Плашка обратного отсчёта в правом нижнем углу за N минут до конца
- 🧰 Гибкие настройки в `settings.json` (задержки, повторы, пороги)
- 🖼️ Иконка в системном трее + контекстное меню (Старт, Пауза/Продолжить, Сброс, Выход)
- 🧷 Единственный экземпляр (Windows named mutex)
- 📝 Логирование с ротацией

Ручной таймер продолжает идти после закрытия игры. Автоматически запущенный таймер при закрытии отслеживаемых игр ставится на паузу, а при следующем запуске игры продолжается.

## Как работают игровые лимиты

Приложение учитывает время, только если одновременно выполняются условия:

1. Game Timer запущен.
2. Процесс игры добавлен в список «Отслеживаемые приложения».
3. Окно этого процесса находится на переднем плане.

Игра в фоне, свёрнутая игра или другая программа на переднем плане не увеличивают ни дневное время, ни прогресс до перерыва. Если игра использует отдельный процесс для окна игры, добавьте именно его `.exe` в список отслеживания.

По умолчанию разрешено до 6 часов игры в день. Дополнительно после каждых 2 часов игры на переднем плане начинается обязательный перерыв на 60 минут. После перерыва цикл начинается заново; если дневной лимит уже исчерпан, блокировка остаётся до полуночи. Прогресс до очередного перерыва сохраняется между перезапусками приложения.

На вкладке «Лимиты и отдых» можно задать дневное время отдельно для каждого дня недели, включить или отключить циклические перерывы, а также изменить время игры до перерыва и его длительность. Настройки применяются и сохраняются сразу. На главной вкладке показаны прогресс до следующего перерыва и время, сыгранное из установленного лимита; во время отдыха отображается оставшееся время перерыва. Там же напротив каждой отслеживаемой игры показывается, находится ли она на переднем плане, запущена в фоне или не запущена.

Ручной таймер — отдельная функция: он может запрашивать время и показывать собственный отсчёт. Для автоматического учёта и применения дневных лимитов и перерывов ребёнку не требуется запускать этот таймер вручную.

## Установка и запуск из исходников

Требования:

- Windows 10/11
- Python 3.10+

Шаги:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python game_timer.py
```

После закрытия окна приложение остается в системном трее; для управления нажмите правой кнопкой по иконке. Чтобы запускать его сразу скрытым, задайте `start_minimized: true`.

## Сборка .exe (PyInstaller)

```powershell
python build_exe.py
```

- Итоговый файл: `dist/GameTimer.exe`
- Скрипт автоматически подберёт иконку (`timer.ico`/`Icon_game_timer.png`) и добавит ресурсы (`settings.json`, `README.md`, и т.д.).

## Настройки (`settings.json`)

`settings.json` — единственный файл настроек, который использует приложение. Файл `timer_settings.json` удалён из проекта как устаревшая копия. Для существующих установок приложение однократно импортирует из найденного старого файла отсутствующие настройки, игры, пресеты и горячие клавиши; текущие значения имеют приоритет, исходный файл не удаляется. Выполненный перенос отмечается файлом `settings.json.legacy-migrated` рядом с активными настройками.

Ключевые параметры (фрагменты):

```jsonc
{
  // Интервалы/задержки
  "periodic_tasks_interval_ms": 1000,
  "process_check_interval_ms": 5000,
  "notification_check_delay_ms": 10000,

  // Авто‑старт по игре
  "auto_start_on_game_detect": true,
  "auto_prompt_dialog_timeout_sec": 8,
  "auto_prompt_text": "Игра обнаружена. Время уже учитывается — не забудь про перерыв.",
  "auto_start_mode": "countup", // по умолчанию; либо "countdown"
  "auto_countdown_seconds": 3600,

  // Цикл: игра на переднем плане, затем обязательный перерыв
  "enforce_play_session_limit": true,
  "play_session_limit_hours": 2,
  "enforced_rest_minutes": 60,

  // Дневные лимиты в часах: ключи 0 = понедельник, ..., 6 = воскресенье
  "daily_limits_by_weekday": {
    "0": 6, "1": 6, "2": 6, "3": 6, "4": 6, "5": 6, "6": 6
  },

  // Плашка обратного отсчёта
  "pre_expiry_toast_seconds": 300
}
```

На вкладке «Лимиты и отдых» доступны семь отдельных дневных лимитов. Например, для 2 часов с понедельника по пятницу и 6 часов в выходные задайте `"0"`–`"4"` равными `2`, а `"5"` и `"6"` равными `6`. Цикл «играть до перерыва» и «длительность перерыва» задаётся отдельно от дневного ограничения. Изменения через эту вкладку сохраняются и применяются сразу; ручная правка `settings.json` применяется при следующем запуске.

Значение `daily_limits_by_weekday` задаётся в часах. Можно установить `0`, чтобы запретить игру в выбранный день; при нулевом лимите отслеживаемая игра будет заблокирована до полуночи. При отсутствии недельной настройки используется совместимый общий параметр `daily_limit_seconds` или `daily_limit_hours`. Параметр `autostart` включает или отключает запуск приложения при входе в Windows; автозапуск включается пользователем отдельно.

## Системный трей

Пункты меню автоматически отражают состояние таймера:

- Старт — запускает таймер
- Пауза/Продолжить — ставит на паузу/возобновляет
- Сброс — останавливает и сбрасывает время
- Выход — завершает приложение

## Мониторинг процессов

Список отслеживаемых процессов задаётся в `settings.json` в разделе `processes`. На вкладке «Главная» список показывает текущий статус каждой отслеживаемой игры. Вкладка «Статистика игр» показывает учтённое время по играм и игровую статистику.

При запуске отслеживаемой игры автоматически запускается таймер в выбранном режиме; уведомление нужно только для того, чтобы сообщить ребёнку о начале игры. Кнопка «Понятно», закрытие окна или его сворачивание не останавливают таймер и учёт игрового времени. Автоматический таймер при закрытии игры ставится на паузу и продолжает отсчёт при следующем запуске.

## Логи и данные

- При запуске из исходников настройки, логи и база данных остаются рядом с проектом.
- В собранном приложении пользовательские данные хранятся в `%LOCALAPPDATA%\GameTimer`, а не во временной папке PyInstaller или в текущей рабочей директории.
- Если одновременно запущено несколько отслеживаемых игр, время засчитывается только для игры, окно которой сейчас на переднем плане.

## Горячие клавиши

- Ctrl+Alt+Up/Down — изменить дневной лимит ±10 минут
- Ctrl+Alt+B — открыть родительское управление
- Ctrl+Space — пауза/продолжение (если задано в текущем `settings.json`)
- Ctrl+R — сброс таймера
- Ctrl+Alt+Shift+Plus — добавить 30 минут (если задано в текущем `settings.json`)
- Ctrl+Alt+Shift+R — полный сброс данных (служебная комбинация для тестирования; не используйте в обычной работе)

Пользовательские сочетания задаются в разделе `hotkeys`; `start_minimized: true` запускает приложение только в системном трее.
Если игра закрыта во время отсчёта до блокировки, отсчёт отменяется. Родительская разблокировка не включает блокировку повторно, пока запущена та же игра.
На экране блокировки есть кнопка «Закрыть игру»: она отправляет обычный запрос закрытия видимым окнам отслеживаемых игр, чтобы игра могла завершиться штатно. Принудительное завершение процесса не выполняется. Экран блокировки остаётся до закрытия игры; если игра не реагирует на штатный запрос, родителю потребуется закрыть её обычным способом Windows.

Перед обязательным перерывом и исчерпанием дневного лимита приложение предупреждает примерно за 5 минут и предлагает сохранить игру. Порог задаётся `limit_warning_seconds`; предупреждения показываются уведомлением из системного трея и всплывающей плашкой в углу экрана.

Родительское управление доступно из меню системного трея и по `Ctrl+Alt+B`. Оно позволяет разово добавить 15, 30 или 60 минут к дневному лимиту и текущему циклу игры, либо снять текущую блокировку до закрытия игры. **Доступ не защищён паролем:** любой, кто может пользоваться компьютером, пока приложение запущено, может открыть это управление через горячую клавишу или меню трея и изменить ограничения. Продление действует до конца текущего дня, не меняет обычное расписание и перестаёт учитываться на следующий день; добавка к циклу сбрасывается после следующего обязательного перерыва. Порог предупреждения настраивается параметром `limit_warning_seconds` (по умолчанию 300 секунд).

## FAQ

- Уведомление об обнаружении игры исчезает слишком быстро?
  - Увеличьте `auto_prompt_dialog_timeout_sec` (например, до 10 секунд). Таймер начинает работу автоматически и не зависит от того, нажата ли кнопка.
- Плашка обратного отсчёта не появляется?
  - Проверьте, что режим — обратный отсчёт (countdown), и `pre_expiry_toast_seconds` > 0.
- Игра запущена, но время не учитывается?
  - Убедитесь, что добавлен нужный `.exe` процесса игры и окно игры находится на переднем плане. Некоторые игры используют отдельный процесс окна; в этом случае добавьте его исполняемый файл.
- Где изменить правила на будни и выходные?
  - Откройте вкладку «Лимиты и отдых». Дневные лимиты и цикл игры/перерыва настраиваются там независимо друг от друга.
